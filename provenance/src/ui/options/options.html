추적 방식

자동 추적

글을 몇 초 보고 있으면 자동으로 추적해요

목록 밖 매체도 검색

목록에서 출처를 못 찾으면 모든 매체에서 찾아요. 이런 결과에는 “목록 밖 출처” 표시가 붙어요.
